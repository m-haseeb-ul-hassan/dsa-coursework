# DSA Coursework

Labs and homeworks from **Data Structures and Algorithms (COMP 200-A)**, Spring 2026, Forman Christian College University.

This repo holds the routine, week-to-week coursework. Larger standalone projects that earned their own spotlight — the Cricket Match Database (nested AVL trees), the Graph ADT Social Network + Hashing project, and the Hash Table collision-strategy comparison — live in their own dedicated repos, linked below.

## Standalone projects (not in this repo)
| Project | Description |
|---|---|
| [cricket-match-database](https://github.com/m-haseeb-ul-hassan/cricket-match-database) | PSL-style match/player tracking system using nested AVL trees |
| graph-social-network-hashing | Social network built on a Graph ADT, plus a HashMap-based spell checker |
| hash-table-collision-strategies | Separate chaining, linear/quadratic probing, and double hashing, benchmarked against each other |

## Structure

Each lab/homework lives in its own folder with its own `README.md` explaining what it covers, the concepts practiced, and how to run it. This mirrors the same pattern used in [comp111-programming-2-coursework](https://github.com/m-haseeb-ul-hassan/comp111-programming-2-coursework).

```
├── labs/
│   ├── lab01-oop-library-hospital/

│   ├── lab04-big-o-notation/

```
